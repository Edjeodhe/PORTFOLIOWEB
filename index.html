More Must Mush

장르 방치형 벽돌깨기
플랫폼 PC 웹 (itch.io) / 모바일 개발 중
팀 구성 팀 프로젝트 (숨쉬었음청년)
진행기간 2026.09 ~ 진행 중
담당 역할 기획, 개발 및 출시 운영
상세 설명 버섯에게 삼켜진 숲에서 수확기를 튕겨 버섯을 수확하는 방치형 벽돌깨기 게임입니다. 버섯 75종 도감, 80개 이상의 균사 트리 강화, 날씨가 다른 5개 지역, 8단계로 자라는 세계수로 성장 구조를 구성했습니다. HTML 프로토타입을 만들어 Unity로 이식하고, 아트 리소스 적용과 캐릭터 리깅, 다국어 현지화를 진행한 뒤 itch.io에 출시해 데브로그로 운영했습니다. 아트 에셋과 효과음, 코드 일부에는 AI 도구를 활용했으며, 현재 모바일 버전을 팀원들과 개발하고 있습니다.
PROJECT DETAIL

More Must Mush 숏폼 마케팅

채널 인스타그램 릴스 (세로 숏폼)
기간 2026.11.06 ~ 11.12 (17편)
팀 구성 팀 프로젝트 (숨쉬었음청년)
성과 7일 조회 6,563회
담당 역할 마케팅 기획, 숏폼 광고 제작, 성과 분석
상세 설명 itch.io 웹 빌드 홍보가 29일간 조회 739회에 그치자, 지표를 분석해 문제를 '유입'으로 짚고 모바일 숏폼(인스타그램 릴스)으로 채널을 바꿨습니다.
전래동화 패러디 × 방치형 시스템 반전 콘셉트로 콘티부터 영상 생성(Veo 3.1), 인게임 녹화, 편집까지 직접 맡아 17편을 만들었습니다.
7일 만에 조회 6,563회(itch.io 29일의 약 9배)를 기록했고, 낮은 팔로우 전환을 개선할 다음 방향까지 정리했습니다.
